# Rolline - Watch Face (Wear OS, Watch Face Format v2)
Watchface personale per Xiaomi Watch 2 Pro. Sfondo: immagine "Rolline" (uso personale).
Le ruote girano (un giro ogni 4 secondi, regolabile in `watchface.xml`), le lancette sono analogiche con i secondi continui.
La chiave di firma e' fissa (`app/debug.keystore`): gli aggiornamenti si installano con `adb install -r`.
